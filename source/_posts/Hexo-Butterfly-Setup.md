## 学习资源收集

在探索计算机底层的过程中，合理利用开源社区资源至关重要。

{% note info modern %}
**提示**：学习数据结构时，务必自己动手用 C++ 实现一遍所有的基础树和图结构，不要只看视频。
{% endnote %}

{% note warning modern %}
**警告**：不要陷入框架的汪洋大海，一定要夯实计算机网络和操作系统的基础！
{% endnote %}
